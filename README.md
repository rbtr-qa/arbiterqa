# ArbiterQA distribution (`rbtr-qa/arbiterqa`)

Public home for **`npx @rbtrqa/cli`**, the agent skill, and the Claude Code plugin.

## npm

```sh
npx @rbtrqa/cli install
npx @rbtrqa/cli login
```
